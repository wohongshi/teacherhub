# 参数设计指南（常见实验配方）

给「参数 → 现象」映射做参考。核心思路：**一个归一化强度函数驱动一切**，再按实验加失败/危险分支。

## 通用强度函数

```js
// 归一化到 0~1.5：各参数按贡献加权求和
intensity(p){
  return ((p.main - min) / (max - min)) * 0.62      // 主控参数（大小/浓度）
       + ((p.temp - tmin) / (tmax - tmin)) * 0.78;  // 温度/能量类参数
}
```
- 强度分档：<0.35 平缓 / <0.72 较剧烈 / <1.05 剧烈 / ≥1.05 剧烈·可能燃烧（或对应实验的极限态）。
- 强度驱动：运动速度 `0.35+intensity`、粒子密度、声音描述、辉光/火焰、**反应时长反比** `duration = 30 - intensity*12`。
- 高温/高压类参数升到极端时必须有**安全分支**（横幅 + 原因）。

## 常见实验配方

| 实验 | 参数 | 现象映射 | 失败/危险分支 |
|---|---|---|---|
| 钠/钾与水 | 金属大小 5 档、水温 5–95℃、酚酞开关 | 大小+温度→强度；浮(密度) 熔(放热) 游(H₂ 推) 响(气泡) 红(酚酞) | 大块+热水→燃烧；钾更剧烈（同结构换色） |
| 铁丝在氧气中燃烧 | 粗细、O₂ 浓度 21–100%、除锈、瓶底处理 | O₂×粗细×除锈→强度；火星密度、辉光、黑色固体 | 未除锈难点燃；O₂ 低火星少；瓶底无防护→炸裂红条+裂纹 |
| 电解水 | 电压/电极间距/电解质 | 电压→气泡速率；两极气泡比 2:1 | 电压过高水沸腾；不加电解质几乎不反应 |
| 丁达尔效应 | 入射光强、胶体浓度、粒子大小 | 浓度→光路亮度；真溶液无光路 | 粒子太大→沉降 |
| 铝热反应 | 铝粉比、引燃方式、环境温度 | 配比→火星与熔融物量 | 未达引燃温度→不启动（红条） |
| 银镜反应 | 银氨浓度、醛浓度、水浴温度 | 浓度+温度→镜面沉积速度 | 温度过高→生成爆炸性雷酸银（红条） |
| 氯气制备 | 盐酸浓度、二氧化锰量、加热 | 浓度→气体流速、颜色深浅 | 未加热几乎不反应；氯气有毒（红条：通风橱） |
| 呼吸作用/酶 | 温度 0–100℃、pH、底物浓度 | 温度→气泡/颜色变化速率 | 过酸过碱过热→酶失活（速率骤降曲线） |

## 读数面板模板字段
1. 条件回显（如 水温 / O₂ 浓度）
2. 反应强度（分档，t=0 显示「—」）
3. 现象 2–3 项（气泡/声音/颜色/状态）
4. 安全 1 项（防护状态，危险时红字）

## 现象字典词条设计
- 用**单字**（浮熔游响红）或双字（引燃/火星/黑固），配 6–10 字解释。
- 判据挂时间轴：`t > 0.3`（出现）、`条件满足`（如酚酞才亮红）。
- 词条常驻舞台底部图例条（不要藏进折叠区）。

## 动态读数写法（放热类通用）
```js
tempNow(p, t){
  const rise = 6 + intensity(p) * 16;         // 升幅随强度
  const up = clamp(t / 1.8, 0, 1);            // 快速上升
  const down = 1 - 0.3 * clamp((t - 8) / 16, 0, 1); // 缓降
  return p.temp + rise * up * down;
}
```

## 画面绘制速查
- 玻璃器皿：圆角矩形/贝塞尔 + 7px 半透明描边 + 左侧高光线。
- 液体：温度色调（冷蓝→暖）、液面正弦波纹（幅度随强度）。
- 火焰：径向渐变水滴形 + `sin(t*13)` 闪烁。
- 火星/气泡：确定性粒子（出生时刻 hash 决定角度速度，年龄决定位置，抛物线加 `190*age*age` 重力项）。
- 落地阴影：`ellipse(cx, 底线+4, rx, 12)` 深灰 12%——器皿和温度计都要有。
