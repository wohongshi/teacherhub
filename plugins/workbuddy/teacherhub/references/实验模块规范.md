# 实验模块规范（一实验一模块）

生成单实验工作台时，**一个实验 = 一个 MODULE 对象 = 一个单文件 HTML 产物**。
框架（HTML 结构 + CSS + 通用 JS）保持不变，只替换 `const MODULE = {...}` 块和顶部 `<title>`/`<h1>`/主题色。

## 纯函数铁律（不可违背）

1. **渲染是 t 的纯函数**：`render(g, p, t, W, H)` 里一切画面只由 `t` 与参数 `p` 决定。
   - 粒子（气泡/火星/飞灰）用「粒子 i 生成于 ti = 起点 + i*周期，位置 = f(t-ti)」的写法，
     禁止在 render 里累加状态。这样拖动进度条、逐帧回看，画面严格一致。
2. **确定性随机**：只用 `hash(n)`（伪随机），禁止 `Math.random()`。同样输入永远同样输出。
3. **教学化简化**：数值是教学曲线（如放热升温先升后缓降），不是真实测量数据；页脚要保留免责声明。

## MODULE 接口

| 字段 | 说明 |
|---|---|
| `key / title / duration` | 模块 id、标题、总时长（秒） |
| `params` | 参数默认值对象 |
| `defs` | 参数定义数组：`seg`（分段按钮，options [{v,t}]，v 可为数字或字符串）/ `range`（滑杆 min/max/step/unit）/ `toggle`（开关） |
| `presets` | 预设场景：`{t:标题, d:一句话说明, p:{参数}}`，2~3 个，至少一个失败/危险对照案例 |
| `dict` | 现象字典：`{k:字, d:解释}`，3~5 条，`k` 要短（单字/两字/四字短语） |
| `events` | 时间线刻度：`{t, k}`，点刻度可跳转 |
| `theory` | 原理卡 HTML（含方程式 .eq + 现象解释 + 为什么） |
| `intensity(p)` | 教学化强度公式（0~1 附近），驱动一切剧烈程度 |
| `activeKeys(p,t)` | 返回 t 时刻点亮的字典 key 数组（字典联动高亮） |
| `phase(p,t)` | 返回 t 时刻的阶段短语 |
| `readouts(p,t)` | 返回 `[{l,v,warn?}]` 实时读数 4~5 行；危险态给 `warn:true` |
| `render(g,p,t,W,H)` | 画布渲染，纯函数（见铁律 1） |

## 参数设计要点

- **强度必须由参数耦合算出**（如 钠：大小+水温；铁丝：浓度×粗细×除锈），不要让参数直连动画。
- 至少 1 个参数带**安全分支**（如 瓶底不防护 → 裂纹 + 红字警示），教学价值最高的对照点。
- 预设按「失败案例 → 典型案例 → 极端/危险案例」排。

## 框架自带能力（模板已内建，新实验照抄即可）

- **📷 截图导出**：一键把当前画布存成 PNG（文件名带时刻），老师截现象图进课件。
- **⛶ 投屏模式**：隐藏侧栏、画布放大（可再进浏览器全屏），课堂投屏专用。
- **⌨ 快捷键**：空格 播放/暂停 · ← → 逐帧 · R 重置 · S 截图 · F 投屏（输入框聚焦时自动忽略）。

## 加新实验的步骤

1. 复制任一模板文件（框架部分原样不动）。
2. 只替换 `<title>`、`<h1>`、`:root` 主题色、`const MODULE = {...}` 块。
3. 画布 960×560，主物件画在中区，图注画在底部（y≈538）。
4. 自检清单：拖动进度条任意来回画面不跳变；三档预设读数互斥可见；危险参数出红字；
   手机宽度（390px）单栏无横向溢出；离线 file:// 直接打开可用。
