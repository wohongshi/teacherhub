# 教师工作台（teacherhub）

教师的教研助手插件：**纯本地干活**，云端只做两件事——记录每位老师的 ima 知识库贡献、沉淀模型工作台产物（先检索复用，避免重复造）。

## 前置：配置一次（老师只需要做这一步）

引导老师运行 `teacherhub ui`（会弹出配置网页），填三样：
1. **云端地址**（管理员在群里发的，如 https://hub.example.com）
2. **教师姓名**（贡献和作品都用它署名）
3. **访问 key**（群里发的统一 key，**别发给学生**）

命令行等价：`teacherhub config --cloud 地址 --name 姓名 --key key`。配置存在老师自己电脑上（~/.teacherhub/config.json）。首次可 `teacherhub ping` 验证连通。

## 三个工作流

### 1. 生成「模型工作台」（实验演示页）——先检索，后生成，自动推送

老师说「帮我做个 XX 实验/演示工作台」时，**严格按顺序**：

1. **先检索**：`teacherhub search "关键词"`（用实验名/主题做关键词）
   - **有类似产物** → 不要重新生成！把检索结果里的**链接**发给老师，并说明是现成的、可直接打开。
2. **没有才生成**：按 `references/实验模块规范.md` 的**一实验一模块**结构（框架不动、只换 MODULE 块；模板见 `templates/实验模板-钠与水.html` / `templates/实验模板-铁丝燃烧.html`）与 `references/参数设计指南.md` 的配方，产出**单文件 HTML**（一个实验一个文件）：
   - 内联 CSS/JS、零外链、断网可开、双击即用；中文界面；手机不溢出
   - 参数可调（滑杆/档位/开关）+ 2~3 个一键预设（含失败/危险案例）+ 现象字典随进程点亮
   - 开始/暂停/逐帧/时间轴拖动回看（确定性模拟：同一时刻同一画面）
   - 危险实验红条横幅 +「⚠ 安全」说明；页脚注明「教学化模拟量值，非精确计算」
3. **自动推送云端**：`teacherhub push 文件.html --title 标题 --tags 化学,实验 --keywords 钠,水,反应 --desc 一句话简介`
   - 返回的**链接**发给老师（这个链接浏览器直接打开）
   - 生成完不推送=白干，推送是流程的一部分

### 2. 记贡献（ima 知识库上新时报一条）

老师说「我往知识库加了 XX」「刚补充了 XX 资料」→：
`teacherhub contrib "添加了《XX》到 YY知识库" --kb YY知识库 --item XX`
署名自动用配置里的教师姓名。云端会按人统计，别漏报也别虚报。

### 3. 看统计

老师问「最近大家都加了什么」「我贡献了多少」→ `teacherhub stats`（或把云端统计页链接发给老师：云端地址 + /stats?key=统一key）。

## 铁律
- **先 search 再生成**——云端已经有了就发链接，别让老师等你重新生成一遍。
- **生成必推送**——push 成功拿到链接才算交付。
- 产物永远是**单文件 HTML**（模板里的确定性模拟规范照抄）。
- **key 不外传给学生**；老师问起就说这是教研组内部的。
- 署名用配置里的教师姓名，不要编名字。
- 云端失败（网络不通）不影响本地生成：照样把 HTML 文件给老师，等网络恢复再补推。

## 命令速查

| 命令 | 干什么 |
|---|---|
| `teacherhub ui` | 配置网页（云端地址/姓名/key） |
| `teacherhub ping` | 测云端连通 |
| `teacherhub search "关键词"` | 检索云端有无类似工作台 |
| `teacherhub push 文件.html --title 标题 ...` | 推送产物，返回链接 |
| `teacherhub contrib "文本" [--kb ...] [--item ...]` | 报 ima 知识库贡献 |
| `teacherhub stats` | 看贡献统计 |

平台：Windows 用 `bin\teacherhub-windows-x86_64.exe`；Linux 用 `bin/teacherhub-linux-*`；Mac（M 系列）用 `bin/teacherhub-darwin-arm64`。命令加 `.\` 或 `./` 前缀运行。
